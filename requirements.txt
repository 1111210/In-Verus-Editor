# In Verus 谱面编辑器
# ------------------------------------------------------------------
# 核心编辑器只依赖 Python 标准库（tkinter / json / dataclasses ...），
# 因此不安装任何第三方包也能完整运行。
#
# 可选依赖（推荐安装）：真实音频播放与精确 seek
#     pip install pygame-ce
# 若当前 Python 版本暂时没有 pygame-ce 轮子，编辑器会自动退化为
# “静音时钟”后端：滚动、缩放、播放/暂停、编辑等功能全部照常可用。
# ------------------------------------------------------------------
