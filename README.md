# In Verus —— 《In Falsus》社区谱面编辑器

本项目是游戏 **《In Falsus》** 的社区谱面编辑器（非官方作品），用于编辑它的
双平面谱面：左边 **6K 下落式**，右边 **鼠标平面**（空域 / 滑键 / 点击），
两边共享同一条判定线与同一套时间网格。

---

## 一屏看全

编辑器把两个平面左右分栏，中间的分界线可以直接拖动调整宽度（双击恢复 1:3）：

![编辑器主界面](docs/images/editor_overview.png)

## 放置物件：点点鼠标就能写谱

单键、多轨、长按、空域、滑键、鼠标点击按键，都只用点击完成；放置过程中有幽灵预览，
可以随时滚动、缩放、改主意：

![放置预览](docs/images/placement.png)

* **单轨 / 多轨按键**：点一下定位置，横跨几条轨道由点击的轨道决定。
* **长按（可跨轨）**：第一下定点，第二下拖到想要的时长。
* **空域**：两次点击定开始 / 结束，再点出左右边界的形状，可在线性 / 缓入 / 缓出间选择。
* **左右滑键**：第一下起步、第二下甩出去，方向与长度都画在画面里。
* **鼠标点击按键**：第一次点中心、第二次点范围，红框 + 菱形一目了然。

## 演示模式：随时查看“玩起来是什么样”

按 `Tab` 进入演示模式，画布直接显示**软件渲染的游玩视角**（只读，不会误改谱面），
空格暂停 / 继续，`Tab` / `Esc` 返回编辑：

![演示模式](docs/images/demo_mode.png)

物件厚度、流速、侧轨高亮在「编辑器设置 → 演示视图设置…」里单独调节，
与谱面文件互不影响。

## 时间轴与谱面设置

* **BPM 列表 + 偏移**：每段自定义起始拍、BPM 与小节拍数，小节线自动重排。
* **速度组**：每条流速记录可正可负，做出加速、暂停、反向、往返等特效；
  物件与速度组双向绑定，位置由“判定时刻落在判定线上”反推。
* **节拍音 / 打击音效 / 音量**：三路音量独立，慢放也不改变音效长度。
* **自动检查**：一键找出重叠、越界、缺音频等谱面问题并直接选中。

## 编辑效率

* 框选、`Ctrl` 对称差选择、复制 / 粘贴保持轨道与横向位置、沿中轴线镜像。
* 单选即可编辑参数（时间、轨道、边界、方向…），全部改动可撤销 / 重做。
* 万级物件仍然流畅：可视窗口渲染 + 差量撤销 + 命中缓存。

## 快速开始

```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

python run_editor.py --make-demo                       # 生成示例谱面
python run_editor.py charts/demo/demo.json             # 打开示例谱面（默认最大化）
python run_editor.py charts/demo/demo.json --windowed  # 普通窗口
python run_editor.py charts/demo/demo.json --demo      # 直接进入演示模式
```

Windows 下也可以直接双击 `run_editor.bat`（会自动优先使用项目里的 `.venv`）。
没有安装 `pygame-ce` 时编辑器仍可完整编辑与播放（静音时钟），只是没有声音与演示模式。

## 常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `1` ~ `7` | 切换工具（选择 / 单轨 / 多轨 / 长按 / 空域 / 滑键 / 鼠标点击） |
| 空格 | 播放 / 暂停（演示模式下为暂停 / 继续） |
| `Tab` | 进入 / 退出演示模式 |
| 滚轮 / `Ctrl+滚轮` | 滚动时间轴 / 缩放 |
| `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴（粘贴时点击目标时间） |
| `M` | 沿中轴线镜像选中物件 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Delete` | 删除选中物件 |
| `F10` / `F11` | 最大化 / 全屏 |
