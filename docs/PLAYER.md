# 游玩器（3D）设计说明与进度

## 引擎选择

* 原编辑器用 tkinter，做不出 3D、也没有足够低的输入延迟，因此游玩器**独立**用
  **pygame-ce** 实现（已在 `requirements.txt` 里），**保留编辑器不动**。
* 没有引入 OpenGL / 新语言：pygame 的 `Surface` + 自写**透视投影**（`game/scene.py`）
  足够画几十个多边形，且能跑满 60~144 FPS；输入用 pygame 的事件队列
  （键盘 / 鼠标事件与帧解耦，避免 tkinter 的回调延迟）。
* 音频复用编辑器的 `rhythm_editor.audio.AudioPlayer`：倍速、系统延迟补偿、
  节拍音 / 打击音都已经在里面验证过（含“音效按软件位置触发”的规则）。

## 已实现（可直接用的部分）

| 模块 | 内容 |
| --- | --- |
| `game/judge.py` | 判定核心：EXACT / Exact / Near / Break（±25/50/100ms，提前 100~150ms 为 Break、更早是空敲不惩罚）；**这些允许误差都按真实时间算 —— 不随倍速改变**（`grade_for_offset` 里把窗口按 `× 倍速` 换算成歌曲毫秒；漏判阈值与滑键收尾同理），而**判定区间长度仍是谱面拍长的半拍**（歌曲毫秒），所以不同倍速下判定数量一致；一次按键最多判定一个点击类物件；长按开头同点击类；长按 / 空域按**半拍一个判定区间**（离开 ≤50ms → EXACT、≤100ms → Exact、>100ms 但曾进入 → Near、从未进入 → Break；长按松键最多 Near，末段提前 50ms 抬起仍 EXACT）；滑键“吸附到最准确瞬间”（EXACT 立即、否则记录最好等级、过线 100ms 收尾）；空域 / 滑键判定范围两边各放宽 0.01；准度与分数公式 |
| `game/scene.py` | 3D 布局与透视：**鼠标合法区宽 = 6K 中间四轨宽 = 1 单位**（与编辑器的 0..1 归一化坐标同一套；6K 总宽 1.5、每条轨道 0.25）；鼠标平面在 6K 上方 `MOUSE_PLANE_HEIGHT`；轨道长度 `START_Z`；两条判定线同处判定平面；相机在判定平面**后方、上方**（俯角 16°）→ 刚出现的按键更小、判定线附近与原来相当、两条判定线看起来更近；两个平面**运动距离相同**；**游玩区整体缩放铺满窗口**（按窗口尺寸重算缩放并居中，不留大片黑边）。观感参数由 `tools/fit_player_framing.py` 在旧单位（合法区宽 1.4）下搜出，scene.py 里统一乘 `UNIT_SCALE = 5/7` 换算到新单位 —— 世界坐标缩了 1.4 倍、相机同步缩 1.4 倍，屏幕上的画面不变 | 
| `game/textures.py` + `assets/textures/player/` | 玩家端预设贴图（47 张，`tools/make_player_textures.py` 生成）：单键 / 长按头部与主体（**背景完全不透明**）/ 空域（单像素边界、填充、判定线 + 淡横纹大图）/ 滑键箭头与主体（直角三角形**直角顶点在滑动方向一侧的边缘中点**）/ 鼠标点击（菱形、范围、边界）/ 轨道默认与按下 / 轨道边界高亮；**加载页一次性读入并规格化**（单像素图变多像素时取平均，其它尺寸不符时拉伸，缺失时用占位）；**贴图按 3D 仿射铺放**（旋转 + 缩放，不再塞外接矩形），长条元素（轨道、长按主体、空域底）用贴图平均色填透视正确的多边形避免阶梯 |
| `game/settings.py` | 玩家设置（全局文件 `player.json`，与编辑器设置分开）：玩家名、6K 键位（默认 shift/a/s/d/f/space）、**单键 / 多轨单键 / 滑键 / 鼠标点击按键各自的厚度**（长按与空域没有厚度）、音频延迟、**流速 1~10（可视毫秒 = 1500 / 流速）**、侧轨高亮、鼠标灵敏度 0.1~10x、无界鼠标、音量、**倍速 0.1~1.5x**、**期望帧率** |

## 已完成：可运行的 GUI（`game/app.py` + `run_player.py`）

```bash
python run_player.py                       # 主界面列出 charts/ 里的谱面
python run_player.py charts/demo           # 直接选中该谱面文件夹
python run_player.py charts/demo/demo.json # 直接选中某个谱面文件
python run_player.py --software            # 强制软件渲染（窗口黑屏 / OpenGL 有问题时）
python run_player.py --opengl              # 强制 OpenGL（启动自检不过会自动回退软件）
```

* **谱面列表**：``charts/`` 下**每个含 json 的文件夹算一张谱面**（文件夹里有多个 json 时取
  “主谱面”：优先 ``chart.json``，其次与文件夹同名，再按名字排序；``_`` 开头的临时文件忽略，
  不含 json 的文件夹不算谱面）。
* **打开其他路径**：主界面底部固定有「＋ 打开其他路径的 JSON…」一行（快捷键 `O`），
  弹系统文件对话框选任意位置的谱面；打不开对话框的环境（无 tkinter / 无显示）会退回
  窗口内直接输入路径；打开过的外部谱面留在本次列表里。
* **主界面**：↑↓ 选择（Home/End 跳首尾）· Enter 确认 · O 打开其他 JSON · S 设置 · Esc 退出；
  底部两行「打开其他路径」「设置」**常驻**，所以**没有谱面时也能进设置**；
  每条显示 **标题 · 艺术家 · 难度 · 初始 BPM** 与相对路径，打开过的谱面带 `*`
  并自动排到最前（最近 8 条，记录在 `player.json`）；
* **设置**：玩家名、6K 键位（6 条，回车逐轨输入）、物件厚度、系统音频延迟、
  **流速（1~10，0.1 一档，可视毫秒 = 1500 / 流速；流速越大物件越快，且**与倍速无关**
  —— 倍速只改变歌曲推进快慢，物件在屏幕上的移动速度保持不变）**、
  鼠标灵敏度（0.1~10x）、侧轨高亮（第 1/6 轨暗紫）、无界鼠标模式；
  数字类选项右侧是 `− ● +`（点 ● 可以自定义输入数值），文本 / 开关类选项没有 `− +`；
  音量（音乐 / 打击）与**渲染后端（软件 / OpenGL）**；
  **期望帧率（屏幕刷新率 / 30 / 60 / 120 / 240）**：只列出不超过屏幕刷新率的档位，
  刷新率本身是最高档（默认跟随）；刷新率按**窗口所在那块屏幕**实时判定，
  多屏刷新率不同也能跟上；游玩界面左下角显示实时帧率与当前上限；
  存在 `player.json`（全局）；
* **倍速**：范围 **0.1 ~ 1.5x**（>1x 为加速，音频同样变速变调）；
  − / + 按钮每次动 0.1，但**点 ● 手输的数值不受档位影响**（只做范围夹取，
  例如直接输入 1.37 就是 1.37x）；
  游玩中按 `-` / `=` 也能调（改倍速自动暂停，按空格继续）。
  **分数 = 准度部分 × 倍速^0.6 ± EXACT 数**（每个 EXACT 额外 1 分，不吃倍率：倍率为正时是加分、为负时是**额外扣分**），
  HUD 会同时显示当前倍速与倍率；
* **OpenGL 渲染（可选）**：`game/glview.py` 把软件绘制的画面作为纹理交给 GL 全屏绘制，
  设置里切到 OpenGL 后立刻生效；没有 PyOpenGL 或创建不了 GL 上下文时**自动回退软件渲染**
  （实测真实窗口下 `renderer_name == "opengl"`，dummy 驱动下自动回退）。
  这一层是为后续做真正的 3D 特效/后期处理预留的管线。
* **加载页**：元数据 + 初始 BPM + 玩家名，1.2 秒后进入游玩（回车 / 空格 / 点一下可跳过）；
* **窗口**：创建时不超过桌面并居中；`F10` 最大化 / 还原、`F11` 全屏（按桌面分辨率）；手动最大化 /
  拉大窗口只会**跟随尺寸**（不会再 `set_mode` 把窗口打回原大小），软件与 OpenGL 都支持；
  `F11` 依次循环 **窗口 → 无边框全屏 → 独占全屏 → 窗口**；
* **自动播放（Autoplay）**：设置里可开；开启后玩家名显示为 Autoplay、**分数倍率 = -倍速^0.6（1.0x 时即 -1.00）**，
  键盘 / 鼠标输入只做**轨道高亮与指针位置**的视觉反馈（不参与判定），
  所有物件与判定区间**完全过线时自动判 EXACT**；
* **鼠标可操作界面**：主界面点谱面行选中、再点开始，底部「打开其他路径 / 设置」点一下即生效，
  滚轮翻列表；设置里点行选中、点行尾 `-` / `+` 调整，再点同一行 = 输入 / 切换；
  结算页与暂停遮罩都有可点的按钮；
* **文字输入**：玩家名走 `TEXTINPUT`（**中文 IME 可输入**）并走与主循环相同的呈现路径
  （OpenGL 后端下也能看到自己打的字）；**键位改为“直接按下想设的键”**，
  两条轨道键重复时会自动交换；
* **游玩**：软件透视 3D（两个水平平面 + 判定平面上的两条判定线；鼠标平面更近更宽；
  **游玩区按窗口尺寸整体缩放铺满窗口**；6K 只画小节线；空域画在鼠标水平面内；
  **鼠标平面是一层蓝底渐变**（靠近判定线略蓝、向轨道尽头渐变为完全透明，不画边线）；
  图层上：6K 平面（含**侧轨高亮**、按下高亮、车道线与小节线）全部画完后再叠加鼠标平面，
  判定线永远在最上层；
  判定线外的物件按时间逐个进入；
  滑键 / 点击按键图案平行判定平面、高度取各自的厚度设置（新单位下默认 0.03 × 5/7）；
  点击按键两侧竖线 + 中央菱形；层序与编辑器一致；鼠标判定线后方三角形标识；
  白线粗细按透视缩放（远处更细）；鼠标指针是**躺在鼠标平面内的矮胖三角形**
  （无界鼠标永远半透明实心；关闭时界内也实心，出界则判定位置实心 + 实际位置只画边线）；
  滑键用“**厚度与不透明度沿滑动方向渐变**（朝向侧更厚更实）”表示方向（中间不画实线），
  鼠标点击按键是**中间厚、两边薄的菱形**（高度与透明度一起从中心向两端渐变，中间一条红色横线
  + 中央固定大小的实心红菱形）；
  判定字符出现在**被判定的物件处**；
  屏幕外物件不绘制）；HUD 左上元数据/BPM/玩家，右上准度/分数/四种判定数量；
  第 0 拍在进入游玩 **1.5 秒真实时间**后到判定平面（与倍速无关：起步歌曲时间 =
  `offset − 倍速 × 1.5s`，为负时先静音等待到歌曲 0 再起播，中间不跳时间；
  **谱面结束后至少等 3 秒**再进结算（画面有倒计时提示）；
  所以**音乐与物件始终同步**）；判定时刻已经过去的物件**立刻不再绘制**（长按 / 空域画到末尾）；
  **比可视范围更远的物件也不画**（`判定时刻 − 当前 ≤ 可视毫秒 × 倍速`，阈值与 z 映射同一个跨度，
  否则低倍速会把物件全挤在起点、高倍速又会半路才冒出来）；
  音频后端每帧 `poll()`（慢放要连续喂窗口，否则低倍速会卡住并断音）；
  慢放的接力必须等**排队段真的开始播**再排下一段（否则会被通道顶掉、音乐漏片段）；
* **按下轨道时对应轨道高亮**（按住期间一直亮，与「侧轨高亮」叠加）；
* **打击音效 + 判定飘字**：命中（EXACT / Exact / Near）响一声白噪声（复用编辑器那套
  `Metronome.play_hit()`，音量取 `player.json` 的 `hit_volume`），并在判定平面上方
  飘出对应等级的文字后淡出；Break 不响。
* **连击**：命中 +1、Break 清零；HUD 显示当前与最大连击，连击 ≥5 时判定面上方
  会显示大号连击数；结算页显示「最大连击」。
* **结算**：**左 1/3 元数据与玩家、右 2/3 分数与各判定数量**（分数行写成「准度部分 × 倍率 + 附加分」，如 `分数：-282842712 + 79`；游戏内 HUD 仍显示总分），
  **分数下面是准度 xx.xxx%（保留三位小数）**，再依次是**「最大连击 x / 总判定数」与「倍速 N.Nx」**（取代原来的“判定数 a / 总数”，保留三位小数；HUD 上的准度同样是三位），
  另有每个判定占**总判定数的百分比**，
  左下 `R 重试`、右下 `Esc 回主界面`；

## 需要你确认的模糊点（我按“最适合游玩”暂定）

1. **图形后端**：暂定 pygame 软件 3D（不装 OpenGL）。如果你想要更好的 3D/粒子效果，
   需要联网装 `PyOpenGL` 或换成别的引擎。
2. **6K 键位**：默认 `shift, a, s, d, f, space` 对应第 1~6 轨（`shift` 在最左）。
3. **一次按键最多判定一个物件**：满足条件时取**时间上最接近**的那个（并列时取 id 小的）。
4. **空敲**：比 -150ms 更早的敲击**不消耗**物件、也不计 Break（完全无惩罚）。
5. **长按**：头部命中后，区间内**只要松过一次键**该区间最多 Near；一直按住 = EXACT。
6. **空域/长按区间数**：按 `[start, end)` 每 0.5 拍一个，不足半拍的尾段不单独计。
7. **滑键**：同一时刻多个滑键时，鼠标位移区间与哪个相交就判哪个（可同时判多个方向相反的滑键）。
8. **准度分母**：用“已完成判定数”（进行中显示），分数分母用“总判定数”（含长按/空域的区间数）；
   总物件数按区间展开计算。
9. **分数**：`round(准度部分 × 分数倍率) ± EXACT 数`（倍率正号：正加、负减），其中准度部分 = `round(已取得准度 / 总判定数 × 1e8)`；**每个 EXACT 的 1 分加减不受倍率大小影响**。
10. **无界鼠标模式关闭时**：判定用的横向位置与三角形标识都夹在 0..1；
    开启时用鼠标实际位置（可以超出）。
11. **首拍延迟 1.5s（真实时间）**：起步歌曲时间 = `第 0 拍 − 倍速 × 1.5s`，音频从这里起播；
    如果已是负数就先静音等待到歌曲 0 再起播 —— 倍速再高也是 1.5 秒真实时间，
    同时音乐和物件保持同步、不会跳过谱面开头。
12. **结算页**：按需求不显示准度，只显示分数与各判定数量。
