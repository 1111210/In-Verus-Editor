# 游玩器（3D）

游玩器是独立的 **pygame-ce** 程序（`run_player.py` → `game/app.py`），
与编辑器共用谱面模型（`model/`）与音频层（`audio.py`），读取同一份谱面 JSON。
玩法语义见 [`GAMEPLAY.md`](GAMEPLAY.md)。

## 1. 运行

```bash
python run_player.py                       # 主界面列出 charts/ 里的谱面
python run_player.py charts/demo           # 直接选中该谱面文件夹
python run_player.py charts/demo/demo.json # 直接选中某个谱面文件
python run_player.py --software            # 强制软件渲染（窗口黑屏 / OpenGL 有问题时）
python run_player.py --opengl              # 强制 OpenGL（自检不过会自动回退）
```

`charts/` 下**每个含 JSON 的文件夹**算一张谱面（有多个 JSON 时取主谱面：
优先 `chart.json`，其次与文件夹同名，再按名字排序；`_` 开头的临时文件忽略）。

## 2. 模块

| 模块 | 内容 |
| --- | --- |
| `game/judge.py` | 判定核心：EXACT / Exact / Near / Break、长按与空域区间、滑键吸附、准度与分数 |
| `game/scene.py` | 3D 布局与透视：世界坐标常量（鼠标合法区宽 = 6K 中间四轨宽 = 1 单位）、相机与投影 |
| `game/frame.py` | **两条渲染路径共用的世界几何**：可见物件筛选、图层、按键 / 滑键 / 点击 / 空域的位置与尺寸 |
| `game/render3d.py` + `glview.py` | Panda3D 离屏渲染；OpenGL 呈现层（把画面作为纹理全屏绘制） |
| `game/textures.py` + `assets/textures/player/` | 玩家端预设贴图（47 张，由 `tools/make_player_textures.py` 生成）：单键 / 长按头与主体 / 空域 / 滑键箭头 / 点击菱形与边界 / 轨道默认与按下 / 轨道边界高亮；加载时一次性读入并规格化（单像素图取平均色、尺寸不符时拉伸、缺失时用占位） |
| `game/settings.py` | 玩家设置（全局 `player.json`，与编辑器设置分开；`VERUS_PLAYER_SETTINGS` 可覆盖路径） |
| `game/app.py` | 主界面 / 设置 / 加载 / 游玩 / 结算的 pygame 外壳，HUD、飘字与输入 |

## 3. 界面与操作

* **主界面**：`↑` `↓` 选择（`Home` / `End` 跳首尾）· `Enter` 开始 · `O` 打开其他 JSON ·
  `S` 设置 · `Esc` 退出；底部「打开其他路径」「设置」两行常驻，没有谱面时也能进设置。
  每条显示 **标题 · 艺术家 · 难度 · 初始 BPM** 与相对路径；打开过的谱面带 `*` 并排到最前
  （最近 8 条记录在 `player.json`）。鼠标可直接点选谱面行、底部按钮与设置项。
* **打开其他路径**：弹系统文件对话框选任意位置的谱面；无对话框环境下退回窗口内输入路径。
* **加载页**：元数据 + 初始 BPM + 玩家名，1.2 秒后进入游玩（回车 / 空格 / 点击可跳过）。
* **游玩**：`F10` 最大化 / 还原 · `F11` 循环 **窗口 → 无边框全屏 → 独占全屏 → 窗口** ·
  `F2` 循环渲染后端 · `空格` 暂停 / 继续 · `R` 重试 · `Esc` 回主界面；
  游玩中 `-` / `=` 调整倍速（自动暂停，按空格继续）。
* **设置**：玩家名、6K 键位（默认 `shift / a / s / d / f / space`，回车逐轨输入）、
  四种物件的厚度、系统音频延迟、流速 1~10、鼠标灵敏度 0.1~10x、侧轨高亮、
  无界鼠标、音量（音乐 / 打击）、渲染后端、期望帧率、倍速、自动播放。
  数字项右侧是 `− ● +`（点 ● 可自定义输入），文本 / 开关项没有 `− +`。
* **重复按键**：把某一轨设成另一轨已用的键时，两个轨道会自动交换。

## 4. 判定与计分

* 判定窗口（真实时间，不随倍速改变）：EXACT ±25 ms、Exact ±50 ms、Near ±100 ms；
  提前 100~150 ms 记 Break，更早的敲击不计入判定也不惩罚。
* 长按与空域按**半拍一个判定区间**评级；滑键取判定时刻起 100 ms 内最准确的一刻。
  按键 / 鼠标事件用自身时间戳进入判定（每帧另有一次采样兜底），
  因此极高 BPM 或掉帧导致一帧跨过多个区间时，区间不会被误判成 Break。
  完整规则见 [`GAMEPLAY.md`](GAMEPLAY.md)。
* 一次按键最多判定一个点击类物件；同时可判多个时取判定时刻最靠前的那个。
* 分数 = `round(准度部分 × 倍速^0.6) ± EXACT 数`（每个 EXACT 额外 1 分，不吃倍率；
  倍率为负时表现为额外扣分）。HUD 同时显示当前倍速与倍率。
* 连击：命中 +1、Break 清零；HUD 显示当前与最大连击，连击 ≥5 时在判定面上方显示大号数字。
* 自动播放：玩家名显示为 Autoplay，分数倍率为 `-倍速^0.6`，所有物件与判定区间过线时自动判 EXACT；
  键盘 / 鼠标输入只保留高亮与指针的视觉反馈。
* 结算：左侧 1/3 显示元数据与玩家，右侧 2/3 显示分数（`准度部分 × 倍率 + 附加分`）、
  准度（三位小数）、最大连击 / 总判定数、倍速与各判定的占比；`R` 重试、`Esc` 回主界面。

## 5. 渲染

* **世界坐标**：鼠标合法区宽度 = 6K 中间四轨宽度 = 1 单位（与编辑器的 0..1 归一化坐标同一套）；
  6K 总宽 1.5（每条轨道 0.25）；鼠标平面在 6K 上方；两个平面运动距离相同；
  游玩区按窗口尺寸整体缩放并居中。
* **位置按速度组反推**：物件的世界 z 由**所属速度组**的 ``∫ v·spb dτ``（滚动毫秒，
  `game/frame.py::scroll_ms` / `note_scroll_ms`）决定，判定时刻一定落在判定平面上；
  剔除（`frame.visible_notes`）与同层绘制顺序也用同一个距离，而不是拍差 ——
  流速可正可负，拍差排序与真实位置无关（见 `docs/GAMEPLAY.md` 第 3 节）。
  游玩器的「流速」设置是整体的可视跨度（1500 / 流速 毫秒），与谱面的速度组相乘叠加。
* **判定线之前的可视段**：相机在判定平面后方，所以反向流速的物件会走到判定线
  **更靠近摄像头的一侧**（z < 0）。可见范围由 `PlayerScene.visible_z_near`
  按窗口尺寸估算（把该平面的投影二分到画面下缘），物件只要落在
  「可视下界 ~ 运动起点」之间就照常绘制；再靠近就掉出画面、不再画。
* **判定区间里时间已经过去的部分不画**：长按 / 空域即使还在判定中，也只画
  「当前时刻 → 它的结束时刻」这一截（`frame.note_z_span` / `frame.region_samples`
  按当前拍截断），不会在判定线之前拖出一条已经判过的尾巴；空域在判定线上的高亮
  也只在它确实压在线上时画（`frame.region_crosses_line`）。
* **图层**：多轨长按 → 单轨长按 → 多轨单键 → 单轨单键 → 空域 → 滑键 → 鼠标点击按键，
  **与编辑器共用** `model/notes.py::layer_rank()`；多轨物件跨得越多越靠下层。
  `game/frame.py` 是两条渲染路径唯一的世界几何来源，跨后端切换时画面位置一致。
* **后端**：默认 Panda3D 离屏渲染（贴图按 3D 仿射铺放、画家算法定层）；可切 OpenGL 呈现层；
  两者不可用时自动回退软件渲染（pygame 自写透视投影）。
* **视觉**：6K 只画小节线；鼠标平面是一层蓝底渐变（靠判定线更实、向远端渐淡，不画边线）；
  判定线两条（6K 白、鼠标青）；按下轨道高亮；侧轨高亮可选；
  鼠标指针是躺在鼠标平面内的矮胖三角形（无界鼠标永远实心；关闭时界内实心，出界则
  判定位置实心 + 实际位置只画边线）；命中时在物件处飘出等级文字并响一声打击音。
* **物件**：6K 按键 / 长按用分片透视贴图；长按开头与单键同厚度（下限 `HOLD_HEAD_MIN`）、
  长按（含开头与主体）按单键贴图的**可见宽度**向内收（`frame.TAP_VISIBLE_FRACTION`），
  横向渲染宽度与单键一致；
  滑键的楔形宽端朝滑动方向；点击按键由左右竖线 + 长条 + 中央固定菱形组成。
  **鼠标图案的贴图中心都对齐鼠标运动平面**：点击图案内容占满整张图（可见部分上下
  各一半，`frame.click_center`）；滑键主体 / 箭头贴图是**双倍高**（上半可见楔形、
  下半完全透明，`frame.slide_center`），所以可见楔形依旧底边贴平面、向上收尖。
  箭头贴在滑动终点**内侧**、宽 = 厚度的一半（贴图 1:2），左右滑键各用自己方向的
  镜像贴图（渲染时不再二次翻转）；箭头美术尚未实装（当前是全透明占位）。
* **剔除**：判定时刻已过的物件立即不画（长按 / 空域画到末尾）；
  比可视范围更远的物件不画（阈值与 z 映射共用同一个跨度 `可视毫秒 × 倍速`）。
* **窗口**：创建时不超过桌面并居中；用户手动改变窗口尺寸时跟随重算，不改回原尺寸。

## 6. 设置文件

`player.json` 存在 `%APPDATA%/InVerus/player.json`（其他系统 `~/.config/inverus/player.json`），
可用环境变量 `VERUS_PLAYER_SETTINGS` 指定别的路径；内容不写进谱面。
