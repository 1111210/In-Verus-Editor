# 操作指南

## 1. 启动

```bash
python run_editor.py                                        # 空白谱面（默认全屏）
python run_editor.py charts/demo/demo.ivchart               # 打开示例谱面
python run_editor.py charts/demo/demo.ivchart --demo        # 直接进入叠加演示模式
python run_editor.py charts/demo/demo.ivchart --windowed    # 窗口模式（F11 切换全屏）
```

## 2. 界面

* **默认全屏**：启动即全屏，`F11` 或「视图 → 全屏切换」随时切换。
* **上方工具栏（分组 + 二级菜单）**：只保留分组入口
  「文件 / 编辑 / 放置 / 视图 / 面板 / 帮助」+「播放 / 暂停」+「演示模式」+ 快速缩放（`−` / `+`）。
  各分组里的具体功能：
  * 文件：新建 / 打开 / 保存 / 另存为 / 退出
  * 编辑：撤销 / 重做 / 复制 / 粘贴 / 镜像 / 编辑物件 / 删除 / 全选
  * 放置：选择、单轨、多轨、长按、停留区域、左右滑键（当前工具会显示在按钮上）
  * 视图：缩放、时间网格细分、横向辅助网格、跳转、播放、演示模式、全屏
  * 面板：元数据 / BPM 与偏移 / 编辑器设置 / 速度组
  同样的分组也挂在窗口菜单栏上（演示模式下工具栏隐藏，菜单栏仍然可用）。
* **中间画布**：编辑器把两个平面**左右分栏** —— 左侧 6K 下落式、右侧鼠标平面，
  两者共享同一条判定线与同一套时间网格（滚动 / 缩放同步）。
  进入演示模式后两个平面**叠加**显示（鼠标平面压在中间四条轨道上）。
* **背景**：纯黑 `#000000`。
* **底部总览条**：整张谱面的概览，白色竖线是当前判定线位置，蓝框是当前视口；
  点击即可跳转。
* **底部状态栏**：左侧是操作提示与光标信息，右侧是物件数量、选择情况与音频后端状态。

## 3. 常用流程

### 3.1 新建一张谱面

1. 「元数据」填写歌曲名 / 歌手 / 难度 / 作者，并「选择文件…」挑歌
   （会自动复制到谱面文件所在的文件夹）。
2. 「BPM / 偏移」设置 BPM 列表与偏移。若不确定偏移，可先设 0，
   播放后听准再微调（例如 +20 / −20 毫秒）。
3. 「编辑器设置」调缩放、网格密度与音频延迟。
4. `Ctrl+S` 保存为 `.ivchart`。

### 3.2 打谱

1. 滚轮找到时间（判定线永远吸附网格），必要时 `Ctrl+滚轮` 缩放。
2. 选「单轨按键」，在 6K 区域点击落点。
3. 「多轨按键」：点第一条轨道，再点另一条轨道（时间以第一次点击为准）。
4. 「长按」：点起点后可以随意滚动 / 缩放，再点结束时刻
   （点在哪里都行，包括鼠标平面上）。
5. 「鼠标停留区域」：点开始时间 → 点结束时间 → 在弹窗里设置左右边界的
   首尾位置与线型。
6. 「左右滑键」：点时间与位置 → 再点一次决定方向与终点。

### 3.3 修改与批量操作

* 用「选择」工具点击物件；空白处拖动框选；`Ctrl` + 点击 / 框选做对称差选择。
* `Ctrl+C` / `Ctrl+V`：粘贴时点击目标开始时间，轨道与横向位置不变。
* `M`：镜像（沿游玩区中轴线）。
* `E`：编辑（只选中 1 个物件时可用）。
* `Delete`：删除；`Ctrl+A`：全选；`Ctrl+Z` / `Ctrl+Y`：撤销 / 重做。

### 3.4 速度组（特效）

1. 先选中要处理的一个或多个物件。
2. 打开「速度组」→「新建组」→「把当前选择加入该组」。
3. 在右侧流速列表里添加记录：例如
   * `从 24 拍起，倍率 2` → 加速；
   * `从 16 拍起，倍率 -1.5` → 反向运动；
   * `倍率 0` → 物件停在原地。
4. 删除组时组内物件会回到默认组。

### 3.5 播放

* 空格开始 / 暂停；暂停时判定线自动吸附到网格。
* 如果画面与声音有偏差，调整「编辑器设置 → 系统音频延迟」（毫秒）。
  典型值：蓝牙耳机 120~250 ms，有线声卡 20~60 ms。
* 没有安装 pygame 时会以静音时钟播放，方便对位但不发声。

### 3.6 演示模式

* `Tab` 进入 / 退出。进入后两个平面**叠加**显示、隐藏工具栏与状态栏，画面只读，
  支持滚轮滚动、`Ctrl+滚轮` 缩放、空格播放 / 暂停、点击总览条跳转。

## 5. 常见问题

**Q：为什么没有声音？**
没有安装 `pygame-ce`，或谱面没有关联音频。状态栏右侧会显示当前音频后端与文件名。
执行 `pip install pygame-ce` 后重启编辑器即可。

**Q：BPM 改了，为什么物件下落速度没变？**
这是刻意的设计：BPM 只影响“拍 ↔ 秒 / 歌曲位置”的换算，物件运动速度由速度组决定，
默认流速 1 时与时间网格严格对齐，因此同样的时间间隔永远对应同样的长度。

**Q：滚动条在哪里？**
没有传统滚动条。用滚轮滚动时间，用底部总览条快速跳转；判定线始终吸附网格。

**Q：能不能移动已有物件？**
本版本支持编辑（`E`）与复制粘贴、镜像来间接调整位置；直接拖拽会在后续版本加入。
