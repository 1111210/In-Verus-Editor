# 操作指南

## 1. 启动

```bash
python run_editor.py                                        # 空白谱面（默认最大化）
python run_editor.py charts/demo/demo.json               # 打开示例谱面
python run_editor.py charts/demo/demo.json --demo        # 直接进入演示模式
python run_editor.py charts/demo/demo.json --windowed    # 普通窗口（F10 最大化 / F11 全屏）
python run_editor.py charts/demo/demo.json --fullscreen  # 无边框全屏
```

## 2. 界面

* **默认最大化**：启动即最大化（仍有标题栏与任务栏）；`F10` 还原 / 最大化，
  `F11` 或「视图 → 全屏切换」进入无边框全屏。

### 滚动手感

* 滚轮一格 = 时间网格一格（`1 / 网格细分` 拍），`Shift + 滚轮` 一次滚动 1 拍；
  滚动后自动吸附回网格，判定线不会停在格子之间。
* **右侧滚动条方向是反的**：往下拖 / 点下箭头是**往回**走（比例 1 = 曲首、0 = 曲末）。
* 「视图 → 侧轨高亮」开启后，6K 的**第 1 / 第 6 轨**背景变成暗紫色，方便定位侧轨。
* 缩放：`Ctrl + 滚轮` 或「视图 → 缩放」（放大 / 缩小 / 重置缩放）。
  最大可放大到只看 **0.2 秒**，方便对细微偏移。
  缩放控制的是**可视秒数**：判定线以上固定显示这么多秒，所以纵向比例是常数，
  每拍有多高由该处 BPM 决定（BPM 变更处之后立刻变密 / 变疏）。
* **分栏宽度可拖**：把鼠标移到 6K 与鼠标平面中间的虚线分界线上，光标会变成左右箭头，
  按住拖动即可**实时**调整两边宽度（两边各自不小于 150 px）；**双击分界线**恢复默认 1:3。
  拖动时不会误放物件；演示模式没有分界线。
* **播放倍速**：顶栏右侧 `［−］［当前倍速］［＋］`，0.1x 一档、范围 0.01 ~ 1.0x；
  从 0.1x 继续减速进入 0.01 一档的细档（0.09 → 0.08 → … → 0.01）。
  变速同时放慢谱面推进与音频（**慢放会同步降低音调**，0.5x 相当于低八度）；
  绘制的物件间隔（缩放）不受影响。
  播放中调节倍速会**自动暂停**在当前位置（状态栏提示），按空格即用新倍速继续；
  暂停时调节则只改设置。

### 照着画面填拍号

* 小节线旁写着「小节 N · 第 M 拍」，拍线旁写着「第 M 拍」（放大后细分格也会标，
  例如「第 16.25 拍」）。
* 打开「BPM 与偏移」「速度组」「编辑物件」时，面板底部会显示
  「当前判定线：第 X 拍（小节 Y 第 Z 拍）」，可以直接抄进输入框。
* **上方工具栏（黑底按钮 + 二级菜单）**：从左到右依次是
  「**文件 / 编辑**」「**谱面设置**」「**放置物件**」「**编辑物件**」「视图」「速度组」
  「音效」「编辑器设置」，最右端固定 **▶ 播放 / 暂停** 与
  **播放倍速 `［−］［1.0x］［＋］`**。各分组的实际内容：
  * 文件 / 编辑（合并为一个一级菜单）：新建 / 打开 / 保存 / 另存为 / 退出，
    以及撤销 / 重做 / 复制 / 粘贴 / 镜像 / 删除 / 全选和**自动检查（谱面合法性）…**
    —— 跑完弹出报告，并自动选中出问题的物件
  * 谱面设置：元数据设置 / BPM 与偏移
  * 放置物件：选择、单轨、多轨、长按（含多轨）、空域、左右滑键、鼠标点击按键
    （当前工具会显示在按钮上）
    （长按工具同时支持单轨与多轨：起点定轨道与时间，第二次点击的横坐标定结束轨道、
    纵坐标定结束时间；点在鼠标区域里则只改时间）
  * 编辑物件：单击直接执行，只在恰好选中 1 个物件时可用
  * 视图：缩放、时间网格细分（含**自定义…**）、横向辅助网格（含**自定义…**）、跳转、
    显示更早的物件、播放、演示模式（游玩器渲染 · 只读）、最大化、全屏
  * 速度组：单击直接执行
  * 音效：**打击音效开关**、**节拍音**（关闭 / 小节音 / 节拍音）、**音量…**
    （音乐 / 节拍音 / 打击音三路音量窗口）
  * 编辑器设置：编辑器设置…、**演示视图设置…**、**操作指南…**、**快捷键…**
    （帮助收在这里；演示视图设置是演示模式专用的画面参数，与游玩器互相独立）
  * 缩放改在「视图 → 缩放」（放大 / 缩小 / 重置缩放）或 `Ctrl+滚轮`
  * 窗口变窄时工具栏自动出现**横向滚动条**（播放按钮与倍速固定在右侧，
    也可以把鼠标移到工具栏上用滚轮左右滚动）
  * 菜单开合：点开分组后**再点一次同一个按钮就是收起**；点画布、滚轮或 `Esc` 也会收起
  * 选择菜单项（或点击工具栏按钮）后，键盘焦点会自动回到画布 —— 空格播放 / 暂停、
    方向键滚动等快捷键可以直接用，不必再点一下画布
  * 视图 / 音效 / 编辑器设置属于全局偏好（存在 `settings.json`）：改动**不进撤销栈**、
    也不会把谱面标记为已修改；撤销谱面改动时不会顺带回退这些设置
  不保留系统菜单栏；演示模式下工具栏隐藏，用 `Tab` 或 `Esc` 返回编辑。
* **中间画布**：编辑器把两个平面**左右分栏** —— 左侧 6K 下落式、右侧鼠标平面，
  两者共享同一条判定线与同一套时间网格（滚动 / 缩放同步）。
  左侧 6K 只占约四分之一宽度，其余的宽度给鼠标平面；鼠标平面在合法区域 0..1
  之外还各留一段显示余量（标注 `-0.45 .. 1.45`），超出 0..1 的区域边界照样看得见。
  进入演示模式后画布显示**游玩器的软件渲染画面**（3D 视角）。
* **背景**：纯黑 `#000000`。
* **右侧竖向滚动条**：朴素的时间轴滚动条 —— 滑块长度代表当前可视时间占全曲的比例，
  拖动滑块 / 点击箭头 / 点击空白翻页都可以移动时间轴（判定线仍然自动吸附网格）。
* **底部状态栏**：左侧是操作提示与光标信息，右侧是物件数量、选择情况与音频后端状态。

## 3. 常用流程

### 3.1 新建一张谱面

1. 「元数据」填写歌曲名 / 歌手 / 难度 / 作者，并「选择文件…」挑歌
   （会自动复制到谱面文件所在的文件夹）。
2. 「BPM / 偏移」设置 BPM 列表与偏移。若不确定偏移，可先设 0，
   播放后听准再微调（例如 +20 / −20 毫秒）。
   **BPM 变更处一定新开一小节**：变更拍不要求落在上一段的小节线上，它自己就是小节线；
   上一段末尾不完整的小节按一整节算，所以变更后的第一拍正好是新小节的第一拍。
   「每小节拍数」填 **0 表示这一段关闭小节线**（只留拍线），之后填回正数即可恢复。
3. 「编辑器设置」调缩放与音频延迟；网格密度改到「视图 → 时间网格细分 / 横向辅助网格」
   （两个子菜单末尾都有「自定义…」）。
4. `Ctrl+S` 保存为普通的 `.json` 文件（编辑器只支持 JSON 格式）。

> **视图 / 音效 / 编辑器设置是全局的**：它们不跟着谱面文件走，而是存在
> `%APPDATA%\InVerus\settings.json`（Windows；其他系统 `~/.config/inverus/settings.json`），
> 换谱面 / 新建谱面都会沿用。老谱面里的 `editor` 段会在第一次打开时迁移进来一次。

### 3.2 打谱

1. 滚轮找到时间（判定线永远吸附网格），必要时 `Ctrl+滚轮` 缩放。
2. 选「单轨按键」，在 6K 区域点击落点。
3. 「多轨按键」：点第一条轨道，再点另一条轨道（时间以第一次点击为准）。
4. 「长按」：点起点后可以随意滚动 / 缩放，再点结束时刻
   （点在哪里都行，包括鼠标平面上）。
5. 「空域」：点开始时间 → 点结束时间 → 依次点击左边界起点、
   左边界终点、右边界起点、右边界终点（未点击的点按默认值预览：左 0 / 右 1）→
   在弹窗里选择线型（也可微调位置）。
6. 「左右滑键」：点时间与位置 → 再点一次决定方向与终点。
7. 「鼠标点击按键」：点一下定中心 → 再点旁边定大小。它显示成**左右两条红色竖线**
   （间距就是按键范围）+ **中间一条红色横线**，三条线的粗细都与 6K 按键的中心实线一样；
   中央还有一个固定大小的**红色实心菱形**，中间横线与菱形都以判定时刻为垂直中点。
   鼠标部分的横向摆放规则：**启用**横向辅助网格时吸附到网格线并夹进 0..1 合法区域；
   **未启用**时按鼠标真实位置放置，即使超出合法区域（出界）也照常放置。

### 3.3 修改与批量操作

* 用「选择」工具点击物件；空白处拖动框选；`Ctrl` + 点击 / 框选做对称差选择。
* **直接拖动**：选中后按住物件拖动，即可同时改**时间（自动吸附网格）**与
  **轨道 / 横向位置**；松手才写入一条撤销记录（`Ctrl+Z` 可整体撤销）。
  鼠标物件的横向吸附按**物件自身的锚点**对齐网格：
  **滑键对齐起点**、**鼠标点击按键对齐中心**、**空域对齐起点处左右边界的中点**
  （因此即使物件是在另一套横向网格下创建的，拖完也一定落在当前网格线上，且长度 / 宽度不变）。
* `Ctrl+C` / `Ctrl+V`：粘贴时点击目标开始时间，轨道与横向位置不变。
* `M`：镜像（沿游玩区中轴线）。
* `E`：编辑（只选中 1 个物件时可用）。
* `Delete`：删除；`Ctrl+A`：全选；`Ctrl+Z` / `Ctrl+Y`：撤销 / 重做。

### 3.4 速度组（特效）

1. 先选中要处理的一个或多个物件。
2. 打开「速度组」→「新建组」→「把当前选择加入该组」。
3. 在右侧流速列表里添加记录：例如
   * `从 24 拍起，倍率 2` → 加速；
   * `从 16 拍起，倍率 -1.5` → 反向运动；
   * `倍率 0` → 物件停在原地。
4. 删除组时组内物件会回到默认组。

### 3.5 播放

* 空格开始 / 暂停；暂停时判定线自动吸附到网格。
* **自动停止**：音乐与谱面**都播完 3 秒**才会停（取两者较晚的一边）。
  没有载入歌曲时不会自动停止（静音时钟一直走，可以当节拍器用）。
* **节拍音（打拍器）**：「视图 → 节拍音」可选 **关闭（默认）/ 小节音 / 节拍音**。
  开启后播放时，每到小节线或每一拍响一声“滴”（小节音更尖、节拍音更沉），
  方便对音和对拍；**慢放不会把这声拉长**（声音固定 45ms，只有两声的间隔跟着音乐变慢）。
  音效是**预先算好时刻**再混进歌曲输出的：极高 BPM 或掉帧都不会漏响，
  跳转 / 暂停恢复也不会补发一串“滴”声；播放中在判定线前方放物件、开关打击音
  以及调整音量都会立刻生效。
  选择会存进谱面的编辑器设置里，下次打开自动沿用。
* **打击音效**：物件到达判定线时会响一声白噪声 —— 单键 / 多轨按键 / 滑键 /
  鼠标点击按键取判定时刻，长按与空域取**开头**；同一拍的和弦只响一声。
  与节拍音一样混在歌曲输出里，和音乐天然对齐，慢放不改变这一声的长度。
* **音量**：「编辑器设置 → 音量」可以分别调 **音乐 / 节拍音 / 打击音效**（0~100%），
  设置会存进谱面里。
* 如果画面与声音有偏差，调整「编辑器设置 → 系统音频延迟」（毫秒，**可为负**：
  负值表示声音比软件位置更早，会反向补偿）。
  延迟按**真实时间**计，编辑器会自动按播放倍速缩放补偿
  （0.5x 时真实 200ms 只相当于歌曲 100ms），所以换倍速不需要重调延迟。
  典型值：蓝牙耳机 120~250 ms，有线声卡 20~60 ms。
* 没有安装 pygame 时会以静音时钟播放，方便对位但不发声。

### 3.6 演示模式

* `Tab` 进入 / 退出。进入后画布显示**游玩器的软件渲染画面**（3D 视角，与游玩器
  一致），隐藏工具栏、状态栏与滚动条，画面只读；不显示分数、判定与元数据。
* 空格可**随时暂停 / 继续**：暂停停在当前时刻（不吸附网格），继续从同一位置接续。
* 演示视图**不画鼠标指针**；左上角提示当前可用的按键（空格 / `Tab` / `Esc`）。
* 画面参数在「编辑器设置 → 演示视图设置…」里单独调：物件厚度、流速、侧轨高亮，
  与游玩器的 `player.json` 互相独立（演示视图固定用软件渲染）。

## 5. 常见问题

**Q：为什么没有声音？**
没有安装 `pygame-ce`，或谱面没有关联音频。状态栏右侧会显示当前音频后端与文件名。
底部状态栏的提示会告诉你是**哪个解释器**缺依赖；按顺序试：

1. 用 `run_editor.bat` 启动（存在 `.venv` 时优先用它），或先激活 `.venv` 再
   `python run_editor.py …`；
2. 在 IDE 里把解释器切换成 `.venv\Scripts\python.exe`；
3. 或者给当前解释器装依赖：`python -m pip install -r requirements.txt`。

装好后重启编辑器，状态栏右侧会从 `silent` 变成 `pygame.mixer`。
每次启动都会把**实际使用的 Python 路径**与音频自检写进 `_diag/audio_startup.log`，
排查时直接看那个文件即可（编辑器本身不会检查或切换解释器）。

若状态栏写的是 `silent（音频设备不可用）`，说明 pygame 装好了、只是**声卡没能打开**
（被别的软件独占、没有输出设备、远程桌面会话等）。插好耳机 / 关掉独占声卡的软件后，
打开「编辑器设置 → 重新初始化音频设备」点按钮重试即可，不用重启编辑器；
启动状态栏与设置面板里都能看到当前用的是哪个解释器。

**Q：改 BPM 之后时间轴会怎么变？**
纵向是按**秒**画比例的（判定线以上固定显示「缩放」设定的秒数），所以
**BPM 变更处之后的时间轴格子会立刻变大小**：高 BPM 段落每拍更短（格子更密），
低 BPM 段落每拍更长。判定线滚过 BPM 变更点时画面不会整屏跳变 —— 比例只由缩放决定。
物件依旧严格压在时间网格线上（默认流速 1 = 网格本身）。

**Q：BPM 变更拍可以随便填吗？**
可以，填在哪一拍就在哪一拍换 BPM，而且**那里一定新开一小节**：上一段末尾不完整的小节
按一整节计入编号，且**变更处一定有一根小节线**（即使那一段关闭了小节线）。
也就是说变更处的小节号会重新对齐，不会在中途错位。

**Q：不想要小节线怎么办？**
把该段的「每小节拍数」填 0 就关闭了这一段的全部小节线（只保留拍线），HUD 会显示
“小节线已关闭”；之后填回正数就会从那一段的起点重新长小节线。

**Q：滚动条在哪里？**
时间导航有三种方式：滚轮（一格 = 一个网格格）、`Shift+滚轮`（一次 1 拍）、
右侧竖向滚动条（拖动 / 翻页）；判定线始终吸附网格。

**Q：能不能移动已有物件？**
本版本支持编辑（`E`）与复制粘贴、镜像来间接调整位置；直接拖拽会在后续版本加入。
