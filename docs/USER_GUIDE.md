# 操作指南

## 1. 启动

```bash
python run_editor.py                                        # 空白谱面（默认最大化）
python run_editor.py charts/demo/demo.json               # 打开示例谱面
python run_editor.py charts/demo/demo.json --demo        # 直接进入叠加演示模式
python run_editor.py charts/demo/demo.json --windowed    # 普通窗口（F10 最大化 / F11 全屏）
python run_editor.py charts/demo/demo.json --fullscreen  # 无边框全屏
```

## 2. 界面

* **默认最大化**：启动即最大化（仍有标题栏与任务栏）；`F10` 还原 / 最大化，
  `F11` 或「视图 → 全屏切换」进入无边框全屏。

### 滚动手感

* 滚轮一格 = 时间网格一格（`1 / 网格细分` 拍），`Shift + 滚轮` 一次滚动 1 拍；
  滚动后自动吸附回网格，判定线不会停在格子之间。
* 缩放：`Ctrl + 滚轮` 或「视图 → 缩放」（放大 / 缩小 / 重置缩放）。
* **播放倍速**：顶栏右侧 `［−］［当前倍速］［＋］`，0.1x 一档、范围 0.1 ~ 1.0x。
  变速同时放慢谱面推进与音频，**音调不变**；绘制的物件间隔（缩放）不受影响。

### 照着画面填拍号

* 小节线旁写着「小节 N · 第 M 拍」，拍线旁写着「第 M 拍」（放大后细分格也会标，
  例如「第 16.25 拍」）。
* 打开「BPM 与偏移」「速度组」「编辑物件」时，面板底部会显示
  「当前判定线：第 X 拍（小节 Y 第 Z 拍）」，可以直接抄进输入框。
* **上方工具栏（黑底按钮 + 二级菜单）**：只保留分组入口
  「文件 / 编辑 / 放置 / 视图 / 谱面设置」+「播放 / 暂停」+「速度组」+「编辑器设置」
  + **播放倍速 `［−］［1.0x］［＋］`**。各分组里的具体功能：
  * 文件：新建 / 打开 / 保存 / 另存为 / 退出
  * 编辑：撤销 / 重做 / 复制 / 粘贴 / 镜像 / 删除 / 全选，以及**自动检查（谱面合法性）…**
    —— 跑完弹出报告，并自动选中出问题的物件
  * 放置：选择、单轨、多轨、长按（含多轨）、空域、左右滑键（当前工具会显示在按钮上）
    （长按工具已合并原来的多轨长按：起点定轨道与时间，第二次点击的横坐标定结束轨道、
    纵坐标定结束时间；点在鼠标区域里则只改时间）
  * 视图：缩放、时间网格细分（含**自定义…**）、横向辅助网格（含**自定义…**）、跳转、
    播放、演示模式（叠加 · 只读）、最大化、全屏
  * 谱面设置：元数据设置 / BPM 与偏移
  * 速度组、编辑器设置、**编辑物件**：单击直接执行（编辑物件紧跟在「编辑」右侧，
    只在恰好选中 1 个物件时可用）
  * 帮助：操作指南、快捷键（两个独立窗口；已去掉「关于」）
  * 缩放改在「视图 → 缩放」（放大 / 缩小 / 重置缩放）或 `Ctrl+滚轮`
  * 窗口变窄时工具栏自动出现**横向滚动条**（倍速按钮与帮助固定在右侧，
    也可以把鼠标移到工具栏上用滚轮左右滚动）
  * 菜单开合：点开分组后**再点一次同一个按钮就是收起**；点画布、滚轮或 `Esc` 也会收起
  不保留系统菜单栏；演示模式下工具栏隐藏，用 `Tab` 或 `Esc` 返回编辑。
* **中间画布**：编辑器把两个平面**左右分栏** —— 左侧 6K 下落式、右侧鼠标平面，
  两者共享同一条判定线与同一套时间网格（滚动 / 缩放同步）。
  左侧 6K 只占约四分之一宽度，其余的宽度给鼠标平面；鼠标平面在合法区域 0..1
  之外还各留一段显示余量（标注 `-0.45 .. 1.45`），超出 0..1 的区域边界照样看得见。
  进入演示模式后两个平面**叠加**显示（鼠标平面压在中间四条轨道上）。
* **背景**：纯黑 `#000000`。
* **右侧竖向滚动条**：朴素的时间轴滚动条 —— 滑块长度代表当前可视时间占全曲的比例，
  拖动滑块 / 点击箭头 / 点击空白翻页都可以移动时间轴（判定线仍然自动吸附网格）。
* **底部状态栏**：左侧是操作提示与光标信息，右侧是物件数量、选择情况与音频后端状态。

## 3. 常用流程

### 3.1 新建一张谱面

1. 「元数据」填写歌曲名 / 歌手 / 难度 / 作者，并「选择文件…」挑歌
   （会自动复制到谱面文件所在的文件夹）。
2. 「BPM / 偏移」设置 BPM 列表与偏移。若不确定偏移，可先设 0，
   播放后听准再微调（例如 +20 / −20 毫秒）。
3. 「编辑器设置」调缩放与音频延迟；网格密度改到「视图 → 时间网格细分 / 横向辅助网格」
   （两个子菜单末尾都有「自定义…」）。
4. `Ctrl+S` 保存为普通的 `.json` 文件（编辑器只支持 JSON 格式）。

### 3.2 打谱

1. 滚轮找到时间（判定线永远吸附网格），必要时 `Ctrl+滚轮` 缩放。
2. 选「单轨按键」，在 6K 区域点击落点。
3. 「多轨按键」：点第一条轨道，再点另一条轨道（时间以第一次点击为准）。
4. 「长按」：点起点后可以随意滚动 / 缩放，再点结束时刻
   （点在哪里都行，包括鼠标平面上）。
5. 「空域」（原鼠标停留区域）：点开始时间 → 点结束时间 → 依次点击左边界起点、
   左边界终点、右边界起点、右边界终点（未点击的点按默认值预览：左 0 / 右 1）→
   在弹窗里选择线型（也可微调位置）。
6. 「左右滑键」：点时间与位置 → 再点一次决定方向与终点。

### 3.3 修改与批量操作

* 用「选择」工具点击物件；空白处拖动框选；`Ctrl` + 点击 / 框选做对称差选择。
* `Ctrl+C` / `Ctrl+V`：粘贴时点击目标开始时间，轨道与横向位置不变。
* `M`：镜像（沿游玩区中轴线）。
* `E`：编辑（只选中 1 个物件时可用）。
* `Delete`：删除；`Ctrl+A`：全选；`Ctrl+Z` / `Ctrl+Y`：撤销 / 重做。

### 3.4 速度组（特效）

1. 先选中要处理的一个或多个物件。
2. 打开「速度组」→「新建组」→「把当前选择加入该组」。
3. 在右侧流速列表里添加记录：例如
   * `从 24 拍起，倍率 2` → 加速；
   * `从 16 拍起，倍率 -1.5` → 反向运动；
   * `倍率 0` → 物件停在原地。
4. 删除组时组内物件会回到默认组。

### 3.5 播放

* 空格开始 / 暂停；暂停时判定线自动吸附到网格。
* 如果画面与声音有偏差，调整「编辑器设置 → 系统音频延迟」（毫秒，**可为负**：
  负值表示声音比软件位置更早，会反向补偿）。
  典型值：蓝牙耳机 120~250 ms，有线声卡 20~60 ms。
* 没有安装 pygame 时会以静音时钟播放，方便对位但不发声。

### 3.6 演示模式

* `Tab` 进入 / 退出。进入后两个平面**叠加**显示、隐藏工具栏与状态栏，画面只读，
  支持滚轮滚动、`Ctrl+滚轮` 缩放、空格播放 / 暂停，以及拖动右侧滚动条。

## 5. 常见问题

**Q：为什么没有声音？**
没有安装 `pygame-ce`，或谱面没有关联音频。状态栏右侧会显示当前音频后端与文件名。
执行 `pip install pygame-ce` 后重启编辑器即可。

**Q：BPM 改了，为什么物件下落速度没变？**
这是刻意的设计：BPM 只影响“拍 ↔ 秒 / 歌曲位置”的换算，物件运动速度由速度组决定，
默认流速 1 时与时间网格严格对齐，因此同样的时间间隔永远对应同样的长度。

**Q：滚动条在哪里？**
时间导航有三种方式：滚轮（一格 = 一个网格格）、`Shift+滚轮`（一次 1 拍）、
右侧竖向滚动条（拖动 / 翻页）；判定线始终吸附网格。

**Q：能不能移动已有物件？**
本版本支持编辑（`E`）与复制粘贴、镜像来间接调整位置；直接拖拽会在后续版本加入。
