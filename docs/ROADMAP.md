# 路线图

In Verus 当前包含两个可运行的程序：**编辑器**（tkinter）与**游玩器**（pygame-ce，
可选 Panda3D / OpenGL）。两者共用 `model/` 数据层与 `audio.py` 音频层。

## 当前功能

编辑器：

* 双平面视图（6K 下落式 + 鼠标平面），编辑时分栏、演示模式叠加
* 全部放置工具、选择 / 复制 / 粘贴 / 镜像 / 拖拽移动 / 编辑 / 删除
* 元数据、BPM 与偏移、速度组、全局编辑器设置
* 播放 / 暂停（含延迟补偿）、节拍音与打击音效、自动检查
* 差量撤销、排序缓存、命中缓存与差分画布（大谱面性能见 `VERIFICATION.md`）

游玩器：

* 判定与计分（EXACT / Exact / Near / Break、长按 / 空域 / 滑键 / 点击）
* 3D 视角与两条判定线，Panda3D / OpenGL / 软件三条渲染路径
* 主界面、设置、加载页、游玩 HUD、结算页
* 倍速、流速、音频延迟、无界鼠标、自动播放等玩家设置

## 后续计划（编辑器）

1. **大谱面进一步提速**：渲染按可视时间窗用 `bisect` 取物件，
   暂停且无输入时跳过整帧重绘。
2. **吸附模式扩展**：吸附到附近物件 / 小节线。
3. **波形显示**：时间轴上方叠加音频波形，辅助对偏移。
4. **撤销栈面板**：可视化历史状态并跳转。

## 后续计划（游玩器）

* 更丰富的特效 / 粒子（现有 OpenGL 呈现管线可直接扩展）。
* 更细的判定统计、本地成绩记录与排行榜。
* 谱面难度星级评估。
