# 路线图

本仓库当前目标是**编辑器**。以下内容记录范围边界与后续计划。

## 已完成（0.1.0）

* 双平面编辑视图与全部放置工具
* 元数据 / BPM 与偏移 / 编辑器设置 / 速度组面板
* 选择、复制、粘贴、镜像、编辑、删除、撤销 / 重做
* 播放与暂停（含系统音频延迟补偿）、演示模式
* 示例谱面、自检脚本、单元测试与画布冒烟测试

## 下一步（编辑器侧）

0. **大谱面性能**（已量测，按性价比排序）：
   * 撤销改为差量快照（当前 10000 物件每次编辑 ~33 ms，是现在最大的剩余热点）；
   * 只遍历“可视时间窗内 + 非匀速速度组”的物件（排序缓存 + `bisect`），
     把每帧开销从 O(全部物件) 进一步降到 O(屏幕内物件)；
   * 暂停且无输入时跳过整帧重绘。
1. **拖拽移动**：直接拖动已选物件改变时间 / 轨道 / 横向位置（当前用「编辑」对话框替代）。
2. **吸附模式扩展**：除网格外支持“吸附到附近物件 / 吸附到小节线”。
3. **波形显示**：在时间轴上方叠加音频波形，辅助对偏移。
4. **撤销栈面板**：可视化历史状态并跳转。
5. **谱面校验报告**：重叠冲突（同轨同拍）、空闲长按、区域越界等提示。

## 播放器 / 游玩器（不在本次范围）

* 判定系统：单轨 / 多轨 / 长按、停留区域（区间内持续判定）、滑键（方向 + 位移）。
* 计分与结算、连击、准确度统计。
* 复用本仓库的 JSON 格式与 `SpeedGroup` 位置推算函数实现特效表现。
